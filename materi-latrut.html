Belajar HTML & CSS

Panduan dasar untuk memahami bagaimana website dibuat, mulai dari struktur HTML sampai mempercantik halaman menggunakan CSS.

Mulai Belajar Contoh Website

1. Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk membuat struktur sebuah halaman web.

HTML menentukan bagian-bagian seperti judul, paragraf, gambar, tombol, link, tabel, dan formulir.

🏗️

HTML

Mengatur struktur dan isi halaman.

🎨

CSS

Mengatur tampilan dan desain halaman.

⚙️

JavaScript

Membuat website menjadi interaktif.

2. Struktur Dasar HTML

Hampir setiap dokumen HTML memiliki struktur dasar seperti berikut: 

<!DOCTYPE html>
<html>
<head>
    <title>Website Saya</title>
</head>

<body>

    <h1>Halo Dunia!</h1>
    <p>Ini adalah website pertama saya.</p>

</body>
</html>
Tips: Biasakan menulis struktur dasar ini setiap kali membuat file HTML baru.

3. Tag HTML

HTML menggunakan tag untuk menentukan jenis elemen. 

<p>Ini adalah paragraf.</p>

<h1>Ini adalah judul.</h1>

<button>Klik Saya</button>

Sebagian besar tag memiliki tag pembuka dan penutup.

Contoh: <p>...</p>

4. Atribut HTML

Atribut memberikan informasi tambahan kepada sebuah elemen. 

<a href="https://example.com">
    Buka Website
</a>

Pada contoh tersebut, href adalah atribut.

5. Heading

HTML memiliki enam tingkat heading, yaitu <h1> sampai <h6>. 

<h1>Judul Utama</h1>
<h2>Subjudul</h2>
<h3>Sub-subjudul</h3>

6. Teks

<p>Paragraf biasa.</p>

<b>Teks tebal</b>

<i>Teks miring</i>

<strong>Penting</strong>

<br>

<hr>

7. Link

Link digunakan untuk mengarahkan pengguna ke halaman lain. 

<a href="https://google.com">
    Google
</a>

8. Gambar

<img
    src="gambar.jpg"
    alt="Gambar pemandangan"
    width="400"
>

Atribut alt digunakan untuk memberikan deskripsi gambar.

9. List

Unordered List

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Ordered List

<ol>
    <li>Buka editor</li>
    <li>Tulis kode</li>
    <li>Simpan file</li>
</ol>

10. Tabel

<table>

    <tr>
        <th>Nama</th>
        <th>Kelas</th>
    </tr>

    <tr>
        <td>Budi</td>
        <td>XI IPA 1</td>
    </tr>

</table>
Tag Fungsi
<table> Membuat tabel
<tr> Membuat baris
<th> Header tabel
<td> Data tabel

11. Form

Form digunakan untuk menerima input dari pengguna. 

<form>

    <label>Nama:</label>

    <input
        type="text"
        placeholder="Masukkan nama"
    >

    <button type="submit">
        Kirim
    </button>

</form>

12. Semantic HTML

Semantic HTML menggunakan tag yang menjelaskan fungsi suatu bagian halaman. 

<header></header>

<nav></nav>

<main></main>

<section></section>

<article></article>

<footer></footer>

13. Apa itu CSS?

CSS (Cascading Style Sheets) digunakan untuk mengatur tampilan halaman HTML.

Dengan CSS kita dapat mengatur warna, ukuran teks, jarak, posisi, layout, animasi, dan masih banyak lagi. 

p {
    color: blue;
    font-size: 18px;
}

14. CSS Selector

Selector menentukan elemen HTML mana yang akan diberi style. 

/* Selector tag */

p {
    color: blue;
}


/* Selector class */

.judul {
    color: red;
}


/* Selector ID */

#header {
    background: black;
}

15. Warna

body {
    background-color: #f5f5f5;
}

h1 {
    color: #2563eb;
}

p {
    color: rgb(50, 50, 50);
}

CSS mendukung nama warna, HEX, RGB, RGBA, HSL, dan format lainnya.

16. Font & Teks

p {
    font-family: Arial, sans-serif;
    font-size: 18px;
    font-weight: bold;
    text-align: center;
    line-height: 1.6;
}

17. CSS Box Model

Setiap elemen HTML dapat dianggap sebagai sebuah kotak.

Content

Isi elemen.

Padding

Jarak antara isi dan border.

Margin

Jarak antara elemen dengan elemen lain.

.box {
    width: 300px;
    padding: 20px;
    border: 2px solid black;
    margin: 20px;
}

18. Display

.box {
    display: block;
}

.box {
    display: inline;
}

.box {
    display: inline-block;
}

.box {
    display: none;
}

19. Flexbox

Flexbox digunakan untuk mengatur posisi elemen secara fleksibel. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

Properti penting:

  • display: flex
  • justify-content
  • align-items
  • flex-direction
  • gap
  • flex-wrap

20. CSS Grid

Grid cocok digunakan untuk membuat layout berbentuk kolom dan baris. 

.container {
    display: grid;
    grid-template-columns:
        repeat(3, 1fr);
    gap: 20px;
}

21. Responsive Design

Responsive design membuat website dapat menyesuaikan tampilannya pada berbagai ukuran layar. 

@media (max-width: 600px) {

    h1 {
        font-size: 28px;
    }

    .container {
        grid-template-columns: 1fr;
    }

}
Tips: Selalu gunakan viewport meta tag agar halaman HTML bekerja dengan baik pada perangkat mobile.

22. Contoh HTML + CSS

Berikut contoh sederhana website yang menggabungkan HTML dan CSS. 

<!DOCTYPE html>

<html>

<head>

    <style>

        body {
            font-family: Arial;
            background: #f5f5f5;
            text-align: center;
        }

        h1 {
            color: blue;
        }

        .card {
            background: white;
            padding: 30px;
            margin: 30px auto;
            max-width: 400px;
            border-radius: 12px;
        }

    </style>

</head>


<body>

    <div class="card">

        <h1>Halo Dunia!</h1>

        <p>
            Saya sedang belajar membuat website.
        </p>

        <button>
            Klik Saya
        </button>

    </div>

</body>

</html>

23. Tips Belajar Web

1. Praktik

Jangan hanya membaca. Langsung tulis dan coba kode.

2. Buat Proyek

Coba buat portofolio, landing page, atau website sekolah.

3. Pelajari Bertahap

Kuasai HTML dan CSS sebelum masuk terlalu jauh ke JavaScript.

Ingat: Tidak perlu menghafalkan semua tag dan properti CSS. Yang penting adalah memahami konsep dan tahu cara mencari referensi ketika lupa.
